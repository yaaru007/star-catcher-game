# Star Catcher - Simple Android Game

A simple 2D arcade game built with pure Android Java (`SurfaceView` + `Canvas`), ready to build automatically into an APK using GitHub Actions.

## How to Get the APK from GitHub
1. Upload all files (including the `.github` folder) to your GitHub repository.
2. Open the **Actions** tab in your repository.
3. Wait for **Build Android APK** to finish with a green checkmark.
4. Click the workflow run, scroll to **Artifacts**, and download **StarCatcherGame-APK**.
5. Extract the ZIP and install `app-debug.apk` on your Android phone.
